# Testly — Quick Knowledge Check

A small, responsive test/quiz app built with plain HTML, CSS, and JavaScript. No build step or dependencies are required.

## Run it

Open `index.html` in a browser, or serve this folder with any static web server.

## Features

- Five multiple-choice questions with explanations
- Answer validation, score tracking, and progress indicator
- Final results with a score-based message
- Restart flow
- Responsive layout and keyboard-accessible controls

## Customize the quiz

Edit the `questions` array near the top of `app.js`. Each question has a category, prompt, answer options, the zero-based index of the correct answer, and an explanation.
